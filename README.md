# rugby-php-app

PHP + MySQL + 素の JavaScript で作る、ラグビー1シーン分析アプリです。

## セットアップ

1. `.env.example` を `.env` にコピーして DB 情報を設定
2. MySQL で以下を順に実行
   - `sql/schema_core.sql`
   - `sql/seed.sql`
   - （任意）`sql/triggers.sql`
   - （任意）`sql/schema_optional.sql`
3. Web サーバのドキュメントルートを `public/` に設定
4. `public/setup.php` で接続確認

## 画面構成

- `public/index.php`: Play 一覧 / 作成
- `public/play.php`: Submission 一覧 / 作成
- `public/analyzer.php`: 横フロー分析 UI（事実 / もしも / 判断理由ブリッジ）
- `public/export.php`: 印刷向けレポート
- `public/api.php`: JSON API

## 現在の仕様（analyzer）

### レイアウト

- ターンは **左→右** に進行
- レーンは縦積みで、**上: 事実 / 下: もしも**
- 判断理由はレーンではなく、**ターン n と n+1 の中間ブリッジ**として表示
- レーンタイトルは縦長表示で、スクロール（パン）中も常時表示

### ブロック操作

- 事実ブロックのクリックで選択・拡大
- 拡大時に入力欄を自動表示
- もしもブロックは複数作成可能（重複制約を避けるため未使用定義を優先）
- 採用中もしもは赤枠表示、`採用解除` 可能
- 削除は左上の小アイコン（拡大時のみ表示）
- ドラッグ並び替え機能は廃止

### 判断理由

- `判断理由 n` タイトル表示は廃止
- サマリーには入力済み理由を小フォントで表示（未入力時は `理由未入力`）
- `基準:` 表示は廃止

### 矢印描画

- 矢印は右向き（右端→左端接続）で描画
- 理由入力あり:
   - 事実 n → 判断理由 n（青実線）
   - 判断理由 n → 事実 n+1（赤実線）
   - 判断理由 n → もしも n+1（緑点線）
   - 採用中のもしも n+1 には赤点線を追加
- 理由未入力:
   - 事実 n → 事実 n+1（青実線）
   - 事実 n → もしも n+1（緑点線）

### 動画連携（YouTube）

- 背景に YouTube 動画を表示
- `video_id` 入力に **YouTube URL または動画ID** を貼り付け可能
- 操作ボタン: 再生 / 停止 / 5秒早戻し / 5秒早送り / スロー再生 / スロー戻し（疑似）
- 動画停止中に事実ブロックをクリックすると、その時刻を `timestamp_sec` に自動入力
- 再生中、現在時刻以下の最新タイムスタンプ事実ブロックを中央へ追従表示
- 要素追加などで再読込が発生しても、動画の再生位置・再生状態を復元

### 入力モード

- `入力モード` ボタンで背景を暗くして入力しやすくする
- もう一度押すと通常表示へ戻る
- 状態は `sessionStorage` に保存

## 既存の改善ポイント

- 表示文言を日本語化し、画面の意味がすぐ分かる構成に調整
- Autosave 時に「保存中 / 保存成功 / エラー」を入力欄で視覚的に表現
- 矢印再描画を `MutationObserver + rAF` で最適化
- Option カードクリックで分岐切替を直感的に操作可能

## ローカルデモ（MySQLなし環境向け）

この実行環境では MySQL クライアント/サーバが使えない場合があるため、`DB_DSN=sqlite:...` で SQLite デモを起動できます。

```bash
./scripts/init_demo_sqlite.sh
php -S 0.0.0.0:8080 -t public
```

`.env` 例:

```env
DB_DSN=sqlite:/workspace/-/storage/demo.sqlite
```

## 注意（MySQL運用時）

- `video_id` カラムは現行DDLで数値型です。
- YouTube URL/文字列IDをそのまま保存する場合は、MySQLスキーマの `play.video_id` 型変更（例: `VARCHAR`）を検討してください。
